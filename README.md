# КТ-Сталь: автопостинг в Instagram

Публікує дописи @kt_stal за розкладом із `queue.json` через GitHub Actions (кожні пів години, не більше одного допису на київську добу). Медіа віддає GitHub Pages з теки `m/`.

- Вимкнути все: змінна репозиторію `ENABLED` ≠ `1`.
- Секрети: `IG_TOKEN`, `IG_USER_ID`.
- Ручний запуск: Actions → post → Run workflow, аргумент `--status`, `--whoami`, `--check <id>` або `--publish <id>`.
- Джерело контенту й черги — бібліотека КТ-Сталь (`70-маркетинг-соцмережі/…/автопостинг`), сюди переносить `sync.py`.
